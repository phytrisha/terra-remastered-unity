# Sources

- `tripo/<Name>/` — Tripo generations (`tools/tripo_make.sh`): model files, `preview.png`, `task.json`, `result.json`.
  `tripo/LOG.tsv` lists every paid generation (date, name, task id, credits, input). Keep these: they cost credits.
- `reference/` — concept art, photos and style references (also usable as Tripo image input or AI Hub `--ref`).
